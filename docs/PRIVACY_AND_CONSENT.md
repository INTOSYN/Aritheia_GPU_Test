# 研究贡献与隐私（0.5.0rc5）

ComputeProof 可完全离线运行。联网检测默认在结束时贡献最小研究记录，并在开始测试前显示收集说明。完整 JSON 和联系信息始终另行确认；拒绝不改变检测预算、结果或功能，也不需要账户。网络控制命令只在 README 的用户教程中说明。

这不是“完全匿名”：设备哈希可以关联同一安装的重复测试，GPU 型号、版本与异常特征也可能组合成指纹。网络服务器和中间代理在连接期间能看到来源 IP。应用不把 IP 写入业务记录，接收服务和反向代理未启用访问日志；不能据此保证云厂商完全不记录网络元数据。

## 默认记录：每张卡不超过 16 KiB

- 本机随机 256 位密钥对 GPU UUID 计算 HMAC-SHA-256。只发送结果；原始 UUID、密钥均不上传。哈希密钥按安装保存在本机权限受限文件中；重置安装身份后无法跨安装去重。无法取得可靠 UUID 时用 null，绝不凭 GPU 型号或序号伪造硬件身份。
- GPU 型号、显存 MiB、开始测试前的图形核心频率 MHz。频率是快照，不是负载平均频率或锁频保证；未知为 null。
- 客户端版本、源码构建摘要、固定参考摘要、Torch/CUDA/驱动版本和种子预算，供判断报告使用的计算协议与兼容环境。
- 总状态、运行 ID、计算能力、请求预算、探针与逻辑 SM 覆盖，以及全部 24 档配置的选择/完成/排除原因。只有请求完成且未观察到异常/场景监控告警时写入 `ALL_PASS`；正常样本也保留环境与覆盖，但不含场景数值、排名或逻辑 SM 异常列表。
- 只有检出异常或流程未完成时，才附加完成范围、检查数量、不一致数量下界、全部 12 场景状态，以及原生 BF16 MMA / FP32 FFMA 的判定、覆盖和异常逻辑 SM 编号。未选、缺失、未完成不能写成通过。

通过、异常和未完成的记录均可贡献，避免数据库只记录失败样本；v3 通过样本标为 `ALL_PASS`，其环境、协议、预算与配置覆盖同样完整保存在压缩摘要中；旧 v2 正常记录没有保存的字段不会事后编造。结果来自未验证客户端；哈希不是设备真实性证明，提交次数不等于独立物理显卡数量，数据库也不能直接代表总体故障率。逻辑 SM 编号不是已确认损坏的物理核心编号。

默认摘要不包含姓名、邮箱、用户目录、主机名、操作系统用户名、原始 UUID/MAC/磁盘序列号、用户文件、私有模型、提示词、stdout/stderr、反例 NPZ 或完整张量。采集器不扫描目录。

## 可选详细 JSON 与联系方式

结束后先在运行目录生成 `contribution/`，其中包含详细研究 JSON、manifest 和内容说明。交互模式必须显示这个目录，姓名与邮箱均可留空，最后再确认上传；非交互模式绝不自动上传详细数据。显式预览方式：

```bash
computeproof research preview-detail runs/my-test
computeproof research upload-detail runs/my-test --confirm <上一步的SHA256>
```

详细研究 JSON 包含所有常规探针行及迭代输出/参考哈希、每探针至多 32 个数值、场景配置与全部适用白名单指标、输入数据/模型/输出内容摘要、精度与数学开关、可用的决策顺序/成员指纹，以及原生核函数各逻辑 SM 的计数。指纹仅用于复测差异定位；不发送候选名单原文，缺少比较器时不据此判断硬件故障。它是完整的**白名单研究记录**，不是原始 `report.json` 的逐字副本，也不是运行目录打包。原始日志、完整反例数组和自由文本细节留在本地。

每卡未压缩上限 512 KiB，服务端压缩上限 256 KiB；超限拒收并提示，不能截断后冒称完整。预览摘要与实际发送内容绑定，修改后必须重新确认。

姓名、邮箱均可留空，分别询问“公开致谢”与“研究联系”的同意；同意上传 JSON 不代表同意提供联系方式。联系方式单独加密存储，不写入 JSON 文件或公开贡献名单。致谢需研究审核，不自动赋予作者资格或承诺发表。

## 存储、期限、撤回

接收地址：`https://data.intc.ca:8443/sci-test`。摘要在独立 `sci-test` MySQL 数据库中，详细 JSON 压缩后保存在接收服务私有持久目录；网页无法浏览下载。客户端没有数据库账号、管理密钥或公共读接口。

在线记录最多保留 365 天；详细 JSON、深测结果与自愿联系方式最多保留 90 天，后台每小时清理一次。保留期以接收时间为起点。服务器设置 500,000 份紧凑记录和 10 GiB 详细日志容量预算；满额时拒绝上传，本地检测继续。rc4 的 `cp_reports_v3` 对正常/异常都保留完整白名单压缩摘要；详细和深测 JSON 保存在 Docker 挂载的私有持久目录，而不是临时容器层。旧表与旧协议保留，旧缺失值仍然缺失。

本地 `research.private.json` 保存每卡随机凭据与接收回执；在支持 POSIX 权限的系统上设置为 0600；Windows 依赖 NTFS 目录 ACL，应使用个人用户目录并限制共享。服务端只存令牌哈希。**不要公开或发送这个 private 文件**。撤回无需登录：

```bash
computeproof research withdraw runs/my-test
```

撤回删除该次运行各卡的在线摘要、详细 JSON、关联深测结果和联系方式。连接失败可原命令重试；摘要重复提交按同一随机记录 ID 去重。网络失败不会无限自动重试或在以后静默补传旧记录；显式 `research retry` 才重试。

本候选版本的运营主体名称、公开联系邮箱和云数据库备份保留政策正在由部署者确认。当前不能承诺所有云备份即时物理抹除；正式公开分发前须补齐这三项并核验备份恢复/到期删除。

## 可选签名参考包

可选签名参考包服务与研究收集地址分别配置。签名包请求仍须单独交互同意，只发送选中卡的型号、显存和频率；这不等于授权上传详细研究 JSON。详细记录始终通过预览摘要和最终确认单独授权。

## 按报告分配的深测

服务端只对获分配报告返回签名 case，客户端凭原回执请求；没有公共列表。case 需预置信任根、原报告绑定、有效期与后端/预算检查。异常或未完成报告可用于分配针对性复核，但未完成本身不是硬件故障结论。

普通数值对比、参考、探针和十二场景均为公开源码，无需私有扩展。专项深测可选用已安装公开后端，也可以在用户另行同意后下载匹配操作系统、处理器架构和 CPython ABI 的私有编译扩展。获取签名 case 说明不等于下载或运行二进制：用户先预览发行者、用途、平台、体积和包摘要，确认后才下载；校验后再次预览预算并确认执行；最后预览待上传结果并确认上传。三项确认相互独立，默认摘要上传或场景资产下载同意不能替代其中任何一项。

编译扩展按当前用户权限在本机运行，不是沙箱。签名和哈希验证来源与完整性，不保证无安全风险或计算正确；用户应信任发行者后再执行。不接受服务器任意 Python/Shell 安装脚本或临时返回的信任公钥，不通过深测修改驱动、频率、功率或电压。拒绝或没有匹配编译包不会阻止公开客户端的常规检测。当前客户端具备分发接口，不表示各平台深测包或相应生产服务已经部署。

具体命令见 DEEP_CASES.md。深测结果单独标记为后续实验，不混同于最初自然任务；只有单独结果上传确认后才发送，不把原始二进制日志或整个输出目录自动打包上传。收集器最多接收每报告 16 次深测 attempt，未压缩 512 KiB/压缩 256 KiB，计入同一 10 GiB 私有 JSON 预算。
